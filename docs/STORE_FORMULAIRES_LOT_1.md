# Store — formulaires, premier lot

Produit rattache a une boutique du vendeur, description et valeurs numeriques controlees ; doublon boutique/ville/compte refuse. Photo JPG/PNG/WebP non vide et 5 Mo maximum, sans pretendre la televerser. Adresse : numero achat Mailport plutot que contenu QR, destinataire requis, instructions limitees. Meme validation avant checkout ; verification finale toujours serveur.

Preuves : tests formulaires et parcours, controle statique Store, lint et compilation. Limites : pas de recette navigateur, de televersement effectif, de migration des anciens produits ou de permissions serveur nouvelles. Formulaires de modification/reprise vendeur encore a terminer. Aucun backend modifie ; aucune completion globale revendiquee.
